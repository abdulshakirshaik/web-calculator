# Web Calculator

A simple calculator I made with plain HTML, CSS and JavaScript. No libraries.

Started this to get more comfortable with DOM events and CSS grid.

## Features

- Add, subtract, multiply, divide
- Percent, delete and clear
- Shows the previous number and operator above the current one
- Keyboard support (numbers, + - * /, Enter, Backspace, Esc)
- Handles divide by zero and the usual floating point weirdness (0.1 + 0.2)

## Run it

Just clone the repo and open `index.html` in your browser.

```
git clone https://github.com/abdulshakirshaik/web-calculator.git
```
